# Optimistic Africa

> Africa's Story is Changing. The Data Agrees.

An interactive data companion and official website for the book **Optimistic Africa** by Dr Anand Kulkarni, supported by Africa No Filter, with a foreword by Moky Makura.

## 🚀 Live Site

Visit: https://eveiana.github.io/Optimism/

## 📚 About

Optimistic Africa showcases data-driven insights about Africa's changing narrative and progress across various sectors.

## 🛠️ Tech Stack

- **React 19** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Lucide React** - Icons
- **Google GenAI** - AI integration
- **Bun** - Package manager & runtime

## 📦 Getting Started

### Prerequisites
- [Bun](https://bun.sh) installed

### Installation

```bash
# Clone the repository
git clone https://github.com/eveiana/Optimism.git
cd Optimism

# Install dependencies
bun install
```

### Development

```bash
# Start development server
bun run dev
```

Server runs at `http://localhost:3000`

### Build

```bash
# Create optimized production build
bun run build

# Preview production build locally
bun run preview
```

### Deployment

```bash
# Build and deploy to GitHub Pages
bun run deploy
```
